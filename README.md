# 구현할 기능 목록

## 입력 및 파싱
- [ ] 한 줄 입력을 `Console.readLine()`으로 받는다.
- [x] 입력이 `""`(빈 문자열)일 경우 합계는 0을 반환한다.
- [ ] 커스텀 구분자 형식 `//{delim}\n{numbers}`을 인식한다.
    - [x] `{delim}`은 `1글자`의 `가시 문자`만 허용한다.
    - [ ] 공백(`' '`), 개행(`\n`), 탭(`\t`), 두 글자 이상(`==`)은 예외 처리.
    - [ ] 정규식 메타문자(`*`, `+`, `.`, 등)도 허용하되 내부적으로 이스케이프한다.
- [x] 기본 구분자(쉼표, 콜론)를 사용한 입력을 지원한다.
- [ ] 구분자로 분리한 후 `빈 토큰("")`이 존재하면 예외를 던진다.
- [ ] 숫자 사이에 공백이 존재하면 예외를 던진다.

## 검증 (Validation)
- [ ] 숫자 토큰이 모두 숫자인지 확인한다.
    - [ ] 음수(`-1`), 문자(`a`), 소수(`1.2`) 입력은 예외.
- [ ] 숫자 범위는 `int`로 한정한다.
    - [ ] 오버플로 시 예외 발생.
- [ ] 숫자 객체(`PositiveNumber`)를 통해 음수 불변식을 보장한다.

## 계산 (Domain Logic)
- [ ] `List<PositiveNumber>`의 합을 계산한다.
- [x] 빈 입력일 경우 결과는 0을 반환한다.
- [ ] 계산 로직은 입력/출력에 의존하지 않는다.

## 출력
- [ ] 정확한 형식으로 결과를 출력한다. → `결과 : {합계}`

## 예외 처리
- [ ] 잘못된 입력은 `IllegalArgumentException`을 발생시킨다.
- [ ] 프로그램은 예외 전파로 종료된다. (`System.exit()` 금지)

## 테스트 (TDD 사이클 단위)
- [x] 빈 문자열 → 0 반환 테스트.
- [x] 기본 구분자(쉼표, 콜론) 합산 테스트.
- [x] 커스텀 구분자(`//;\n`) 인식 테스트.
- [ ] 잘못된 커스텀 구분자 예외 테스트.
  - [ ] 커스텀 구분자가 2글자 이상일 경우 테스트
  - [ ] 커스텀 구분자에 공백이 존재할 경우 테스트
  - [ ] 커스텀 구분자에 개행 문자가 포함될 경우 테스트
  - [ ] 커스텀 구분자로 숫자가 들어올 경우 테스트
- [ ] 음수/소수/문자 입력 예외 테스트.
- [ ] 공백 포함 입력 예외 테스트. (` 1,3:4`, `1,3:4 ` )
- [ ] 빈 토큰 예외 테스트. (`1,,1`)
- [ ] 정규식 메타문자 구분자 허용 테스트.
- [ ] 선행 0 허용 테스트. ("01,2" -> 3)
- [ ] 출력 형식 일치 테스트 (`결과 : n`).
